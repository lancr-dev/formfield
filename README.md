# Form & Field | Website

A Bento Grid website showcase by **Lance Ducante**, built to help potential clients explore this design style and find a direction for their own website.

Built with standard HTML, CSS, and JavaScript. The visual identity combines forest green, orange, ivory, and lilac with locally hosted Bricolage Grotesque and Onest fonts.

## Features

- Responsive Bento layouts and original brand concept previews.
- Sticky navigation, a mobile sidebar, and dark mode with a saved preference.
- Filterable concept gallery and an interactive layout and palette playground.
- Project brief builder with validation, editing, and text-file downloads.
- Keyboard focus support, accessible controls, and reduced-motion styles.

## Project files

- `index.html` — page content and structure.
- `style.css` — layouts, themes, typography, and CSS illustrations.
- `script.js` — navigation, theme preferences, filters, playground, and brief builder.
- `assets/` — SVG favicon, PNG logo, and local fonts with their license files.

Project briefs are generated in the browser; no form data is sent to a server. The showcased brands are original design concepts. Browser and device testing is handled by the project owner.
